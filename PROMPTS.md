# Acadza triage prompts

The application reads `scripts/triage/prompts/batch_triage.txt` for each five question group. `scripts/triage/engine.py` appends the contents of `verify_answer.txt` as independent verification instructions for proposed answer key repairs. The model must return one JSON object per group, keyed by `group_index`; Python validates taxonomy, edit scope, exact source text, confidence, and route.

Student replies are generated by `scripts/triage/reply_templates.py`. They are never sent to Gemini. `python scripts/run_triage.py --dry-run` supplies the engine's preserved deterministic analysis as mock responses. Those responses are a local reference only and are not represented as Gemini output.

Live calls are opt-in through the command line and require `GEMINI_API_KEY` in `backend/.env`. The CLI saves resumable batches to `data/triage_progress.json`, processes batches sequentially, and stops at ten API calls. FastAPI startup and the React application do not invoke Gemini. The source question, report, and taxonomy datasets are read-only inputs.
